# 剧本质量检查项（参考层 · 打分时取证用）

> 用途：给 9 个细项打分时，用这些检查项在原文里**找证据**。命中"问题信号"的地方，就是扣分的依据，写进逐项分析和致命问题。
> 这些检查项来自三义写作规则中"能判断达不达标"的部分，已改写成评审口径。
> **不加分、不设门槛、不改权重**：检查项只帮助定档，评级上限仍只由 SKILL.md §5 决定。
> 不要求每项都写进报告；只写命中的问题和最能支撑高分的亮点。

---

## 一、题材合同（→ 题材设定、创新度）

先判断项目的**主题材 + 至多两个子题材**，再看两件事：该题材"必须持续兑现"的东西有没有持续兑现；有没有踩"节奏红线"。

| 题材/子题材 | 必须持续兑现 | 节奏红线（问题信号） |
|---|---|---|
| 升级流/成长流 | 成长有可见梯度；每次突破改变能做什么、面对谁、付什么代价 | 换数字、换敌人、换地图当成长；能力万能 |
| 修仙/玄幻成长 | 力量层级、资源、能力边界与身份处境互相影响 | 用境界名词替代训练、代价和成果；战力随剧情伸缩 |
| 宗门修仙/仙门群像 | 宗门、师承、阵营秩序真实影响资源、站队与冲突 | 没有社会秩序与资源来源 |
| 女频情感/女性成长 | 被看见、被选择、自我价值、关系边界或成长回报持续发生 | 把受苦、牺牲、被追求本身当情绪价值；角色被动 |
| 恋爱/甜宠/奇幻言情 | 注意 → 特殊对待 → 拉扯/共同选择 → 关系阶段变化 | 重复撒糖；用误会、宿命、亲密动作替代关系推进 |
| 关系悬疑/女频悬疑 | 关系变化成为线索；物证、人证、情绪反应相互校验；真相可回看 | 只谈感情不推进调查；反转牺牲公平线索 |
| 悬疑灵异/异界规则 | 规则可验证、有来源、可被有限利用；破局有代价 | 堆诡异名词、随意改规则、无代价破局 |
| 规则怪谈/推理 | 观众看得见的线索、可利用的漏洞、能回溯的真相 | 藏关键证据、临场补规则、谜题压垮理解 |
| 都市脑洞/日常异变 | 日常与异常形成反差；异常真实影响生活、关系、成本 | 设定升级快过人物适应与行动 |
| 经营/种田/团队建设 | 资源、成本、积累与阶段成果可见，并反哺关系或主线 | 经营写成报表；收入成本扩张凭空发生 |
| 逆袭/复仇/打脸 | 压迫具体可见；主角靠准备、选择与行动拿到回报 | 靠路人震惊、反派降智或偶然身份救场；同规模重复 |
| 宅斗宫斗/豪门关系 | 权力、资源、名分、信息与关系位置决定代价 | 靠降智误会拖戏；现代项目照搬古装逻辑 |
| 民俗怪谈/恐怖 | 明确禁忌、具体后果、可感知威胁与受限破局 | 无来源惊吓、血腥堆砌、结尾解释抹掉恐惧 |
| 沙雕脑洞/轻喜剧 | 反差来自人物目标、信息错位或严肃规则被日常方式解决；笑点有后果 | 靠降智、无因果冷笑话或网络梗堆叠 |
| 双男主/伙伴冒险 | 双核心各有不可替代目标、能力与立场；合作与分歧均改变结果 | 一人万能，另一人只作工具或捧哏 |

补充判断：

- 子题材夺走了主题材的核心承诺 → 题材设定扣分。
- 两类题材元素不能在同一场戏里互相制造行动与后果，是**拼贴**，不算创新 → 创新度不得因"跨题材"给高档。
- 日常/呼吸集如果一项"必须持续兑现"都没服务，记为注水集。

## 二、人物（→ 主角塑造、人物关系、反派/配角）

| 看什么 | 问题信号 | 影响细项 |
|---|---|---|
| 主角魅力四来源：主动欲望、可识别缺口、外显反差、不可替代性 | 缺任何一项；被剧情推着走；换个人也能完成这件事 | 主角塑造 |
| 主角的选择与代价 | 关键结果由别人替他完成；选择不付代价；每个阶段没有一次两难选择 | 主角塑造 |
| 人物转变的节奏 | 前四分之一集数就完成转变；转变没有在行动和关系后果里铺垫，一句台词宣布"我变了" | 主角塑造 |
| 核心关系的"刺"（利益绑定、情感债、秘密、价值冲突） | 核心关系里一根刺都没有；刺埋了但从来不被碰到 | 人物关系 |
| 关系变化的呈现 | 靠台词宣布"我们关系变了"，没有站队、决裂、守护、背叛之类的可见事件 | 人物关系 |
| 对手戏 | 角色轮流说功能说明，没有"先救谁、信谁、拿什么交换"的真实分歧 | 人物关系 |
| 反派的价值观与资源 | 反派没有自洽的道理；没有资源和行动方式；为坏而坏 | 反派/配角 |
| 反派的压迫层级 | 一直用同一种压迫，没有从轻视到羞辱、剥夺、围猎、公开碾压的升级 | 反派/配角 |
| 反派怎么输 | 输给自己的愚蠢，而不是主角的准备与选择 | 反派/配角、情绪阈值 |
| 配角 | 只负责递线索、解题、卖萌；常驻配角整集没有行动、关系后果或价值选择 | 反派/配角 |
| 新角色出场 | 欲望、能力、短板、与主角的立场差缺两样以上；"一次委托后立即入伙"式速熟 | 反派/配角、人物关系 |
| 口吻辨识度（**删名测试**：遮住角色名只看台词和动作） | 分不出谁是谁；全员同款表情、同款副词、同款总结句 | 主角塑造、人物关系 |

## 三、场景与台词（→ 节奏与反转、情绪牵引、主角塑造）

**每场戏**：能不能说出"角色目标 → 具体阻碍 → 尝试行动 → 可见结果/局势变化"。说不出来，或者这场戏结束后人物状态、关系、资源、信息、风险都没变 → 记为无效场景（影响节奏与反转；连续出现时也是"起伏"检查不成立的证据）。

**台词功能**：关键台词至少承担一项——推进行动、暴露关系或秘密、制造冲突或逼迫选择、交代当下必要信息、制造反差或可回收伏笔。一项都不承担的台词成片出现，是节奏问题。

**台词问题信号**（影响情绪牵引；集中出现时也影响主角塑造）：

| 问题信号 | 怎么认 |
|---|---|
| 复述已知设定 | 角色互相讲双方早就知道的事 |
| 讲课式交代 | 连续几句解释规则，没有"规则触发 → 角色受影响 → 立刻行动" |
| 旁白重复画面 | VO/OS 说的是画面已经表达的内容，或偷运世界观解释 |
| 括号替角色解释情绪 | "（其实在害怕）"这类标注代替动作 |
| 情绪靠结论 | "他意识到""内心涌起"等不可拍的结论句 |
| 报告链 | 对话变成"A 问—B 完整回答—A 总结"，没有打断、回避、答非所问 |
| 通用反应堆叠 | 连续使用"缓缓、淡淡、微微、瞳孔一缩、心中一凛" |
| 整齐闭环 | 每段都走完"起因—经过—结果—感悟"，感悟重复 |
| 关键信息藏太深 | 主线目标、规则、因果结果只藏在潜台词里，观众听不懂 |
| 轻喜剧无后果 | 笑点靠降智、无因果冷笑话或网络梗，笑完剧情没变化 |

**删解释句测试**：把解释性总结句遮掉，只看动作、停顿、道具、站位，观众还能看懂情绪与关系变化吗？看不懂 → 情绪主要靠台词说明，对应"情绪牵引 6-9"档的描述。

## 四、当集兑现（→ 情绪牵引、情绪阈值）

每集找一个完整的兑现链条：

`建立期待 → 可理解的阻碍 → 角色尝试并承担风险 → 画面可见的兑现 → 兑现带来新代价或新局面`

| 问题信号 | 影响细项 |
|---|---|
| 整集只拖延答案，没有任何小答案、可见结果、失败后果或更大麻烦 | 情绪牵引 |
| 兑现靠台词说"赢了""真相是……"，画面上没有发生 | 情绪牵引 |
| 兑现之后什么都没改变，下一集当没发生过 | 情绪阈值 |
| 峰值重复、压迫没有兑现、反杀靠巧合 | 情绪阈值、情绪牵引（口径见 `情绪事件词汇.md`） |

## 五、结构与信息释放（→ 主线与追看、题材设定、节奏与反转）

| 看什么 | 问题信号 | 影响细项 |
|---|---|---|
| 世界观释放 | 设定在前几集一次性倒完；靠连续命名新机构、新编号、新能力伪造复杂度；设定要作者额外解释才能懂 | 题材设定、主线与追看 |
| 悬疑线索与真相 | 真相揭晓时回看不到对应的线索；临场新增设定解释反转；线索只是拖延答案 | 主线与追看 |
| 相邻剧集基调 | 连续三集以上是同一个主导基调（一直紧张、一直虐、一直甜） | 节奏与反转 |
| 呼吸集/日常集 | 情节放松时，关系、伏笔、经营一项都没推进，只是闲聊 | 节奏与反转、主线与追看 |
| 第 1 集的"建立 + 留住" | 看完第 1 集说不清主角是谁、想要什么、处于什么困境；看不出全剧核心矛盾或卖点 | 主线与追看、题材设定 |

## 六、一致性（→ 能不能做、证据可信度）

| 看什么 | 问题信号 | 影响 |
|---|---|---|
| 设定与事实 | 设定前后矛盾；时间线穿帮；角色知道了他不该知道的事 | 相关细项扣分，并在逐项分析中列出位置 |
